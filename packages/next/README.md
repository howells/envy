# `@envy/next`

Next.js helpers for Envy.

This package is scaffolded. It will own `envy init next` and `envy sync next` implementation details for generating explicit client env mappings.

Recommended layout:

```txt
src/env/schema.ts
src/env/server.ts
src/env/client.ts
```
