# `@envy/cli`

Command-line interface for Envy.

This package is scaffolded. It currently exposes the planned command registry and a placeholder `envy` binary.

Planned command families:

- `envy check local`
- `envy check vercel`
- `envy check railway`
- `envy push vercel`
- `envy push railway`
- `envy init next`
- `envy sync next`
- `envy init lint`

See [CLI Guide](../../docs/cli.md).
